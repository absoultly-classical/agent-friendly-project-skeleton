# 学习通会议

学习通会议是一个面向学校、教师和学生的音视频协作产品原型。它把通用会议能力与
学习通已有的课程、班级、教学活动和学习数据结合起来，让课堂、教研、答辩、培训
和行政会议都能在同一入口完成。

私有体验地址：<https://learning-meeting.sizes-mildest-2p.chatgpt.site>

## 当前版本

- 会议首页、快速会议、预约会议和会议号加入。
- 会议中心和会中支持本地邀请引用，打开后可校验并预填会议号。
- 普通会议与课程课堂两种模式。
- 会中视频宫格、音视频状态、共享、录制和布局切换。
- 本地 WebRTC 会话可使用浏览器 `MediaRecorder` 生成 WebM 录制，并在报告页预览或下载；同一浏览器支持 IndexedDB 时会按会议号保存本机录制，重新打开历史报告仍可恢复。
- 成员到课状态、聊天、签到、投票、测验和随机选人。
- 课后出勤、互动、录制和待办报告。
- 桌面和手机端响应式体验。
- 当前页面上传的资料可以下载原文件；图片、视频和音频支持真实本地预览；单页应用内切换页面会保留文件内容，支持 IndexedDB 的浏览器刷新后也可恢复文件内容；不支持时降级为只恢复资料元数据。文件始终只保存在本机，不同步云端。

当前版本由前端交互原型和本地 WebRTC 实验组成：在同源的两个浏览器窗口中，可以请求真实摄像头/麦克风并建立点对点音视频连接。
产品数据、账号、课程、班级、服务端信令、跨设备通信、TURN 中继和云端录制仍未接入；本地 WebRTC、录制和 IndexedDB 文件仅用于同源本机实验，不是生产会议服务。
