# Agent 友好型项目骨架

这是一个以项目文档作为 Agent 长期上下文的通用项目骨架。它不要求 Agent 记住
历史聊天，也不要求用户掌握额外命令；协作过程通过自然语言完成，关键知识则持续
沉淀在版本化文档中。

人类贡献者可以从 [`docs/README.md`](docs/README.md) 开始了解项目；Agent 必须先读
[`AGENTS.md`](AGENTS.md)。

## 怎么使用

把这个骨架用于真实项目时，可以直接告诉 Agent：

> 请阅读 AGENTS.md 和项目知识地图，把产品、架构及开发文档中的占位内容替换为
> 当前项目的真实信息。不要依赖我们此前的聊天内容。

提出新需求时，可以说：

> 请先为这个需求创建任务文档，明确目标、范围、必读上下文和验收标准，再开始
> 实现。工作过程中同步维护项目文档，完成后留下可接手的交接记录。

恢复工作时，可以说：

> 请忽略聊天历史，从 AGENTS.md 开始读取项目文档，根据 ACTIVE.md 找到当前任务并
> 继续执行。如果文档不足，先指出缺失信息。

## 设计原则

- **渐进式读取：** 根目录只提供入口，Agent 按任务需要逐层读取上下文。
- **项目即记忆：** 目标、约束、决策、进度和交接都保存在仓库中。
- **可审查：** 每项工作都有范围、完成标准、验证证据和明确下一步。
- **及时沉淀：** 聊天负责即时沟通，项目文档负责保存以后还需要知道的事实。
