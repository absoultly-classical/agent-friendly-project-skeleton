# 产品需求

| 编号 | 需求 | 验收证据 | 状态 |
| --- | --- | --- | --- |
| REQ-001 | 用户可以快速发起、预约或通过会议号加入会议。 | 首页原型可完成三种入口交互；加入时可关闭全部媒体并以无媒体状态进入，只有开启媒体时才要求媒体采集能力；无媒体会话需重新加入才能开启媒体；会议号限制为 6–18 位数字，输入中的空格或短横线可归一化，其他字符会被拒绝；会议中心和会中可以复制当前本地邀请引用，打开引用后会校验并预填会议号与会议模式，首次读取后消费分享参数避免刷新重复打开；从会议中心进入会中后可返回真正的会议首页。 | 已实现 |
| REQ-002 | 课程课堂可以关联课程与班级，并自动生成参会范围。 | 创建课堂面板展示课程、班级和人数；切换课程课堂与普通会议模式时保留用户已填写的自定义主题。 | 已实现 |
| REQ-003 | 会中提供麦克风、摄像头、共享、录制、成员和聊天控制。 | 会议控制台可操作并显示状态反馈；录制使用 `MediaRecorder` 生成 WebM 媒体，停止、结束会议和卸载时清理录制器，能力不足或轨道无效时显示错误且不伪造成功；支持 IndexedDB 时按会议号保存录制，历史报告只恢复对应会议的本机 Blob，不同会议不会串档；更多设置和成员、聊天、课堂互动侧栏支持按钮切换和 Escape 关闭，关闭后恢复对应触发按钮焦点；侧栏标签通过 tab/tabpanel 关系暴露当前视图和对应内容，采用 roving tabindex 并支持方向键、Home/End 切换；会中设置菜单支持打开后自动聚焦和菜单项键盘导航；会议模式、课堂互动类型和会议中心状态筛选按钮暴露当前按下状态；同源聊天对消息结构、原始/规范化单条 2000 字符长度和发送者名称边界做校验，会话计数最多 100,000 条且可见历史最多保留最近 200 条；旧频道排队消息不会污染重入后的会话。 | 已实现 |
| REQ-004 | 主持人可以发起签到、投票、测验和随机选人。 | 教学互动面板可切换并发布示例活动。 | 已实现 |
| REQ-005 | 会中能识别已到、迟到和未到成员。 | 成员面板按状态展示班级名单。 | 已实现 |
| REQ-006 | 会后形成出勤、参与、互动、录制和待办报告。 | 课后报告页展示各维度摘要；本地录制成功后可在回放区域使用真实 WebM 预览和下载，支持 IndexedDB 时重新打开对应历史报告仍可恢复，不同会议不会串档，未生成文件时不会提供虚假的下载入口；本地报告的待办勾选和新增状态按会议号保存在本机，静态演示报告不写入本机待办；同源其他窗口更新对应会议的待办键后，当前报告会同步勾选状态和新增任务；回放查看区支持显式关闭和 Escape 关闭，关闭后恢复打开入口焦点，并可将当前本地会话的数量和已发布活动明细导出为本地文本摘要；异常或超大分享快照会安全回退。 | 已实现 |
| REQ-007 | 手机和桌面端均能完成主要流程。 | 响应式布局在常见宽度下可用；窄屏会中保留共享屏幕、录制、成员、聊天、课堂互动和布局切换入口，打开侧栏时改为视频区与侧栏上下布局，顶部标题和会议号可收缩，空间不足时仅中央控制组可横向滚动；报告摘要在窄屏改为纵向排列，报告操作和会议资料/回放顶部工具区保持可达且不产生横向挤压。 | 已实现 |
| REQ-008 | 第一版明确说明音视频为交互原型，不伪装为生产通信服务。 | 产品界面和任务记录标注原型边界。 | 已实现 |
| REQ-009 | 用户可以集中查看即将开始、已结束和由自己创建的会议。 | 我的会议页面支持状态分组、按主题/类型/会议号搜索和主要操作；全局搜索、通知浮层、个人菜单和会议行操作菜单保持互斥，并通过展开状态、关联区域语义和关闭后的焦点恢复向辅助技术暴露关系；个人菜单和会议行菜单打开后自动聚焦首项并支持方向键、Home/End 导航；通知已读状态会在本机刷新后保留，并通过同源 `storage` 事件同步；主导航切换和报告返回首页会清理全局搜索/通知及会议定位上下文；预约结束后会转入已结束；全局搜索会纳入当前本机预约与本机创建历史，并按会议号精确定位同名会议；同源窗口写回会合并不同房间的本机记录；旧历史缺少模式字段时按会议类型兼容恢复；本地恢复也遵守主题、房间号、展示元数据和字段白名单边界，并在过滤无效记录后再限制最多恢复 20 条，避免异常前缀遮蔽后续合法会议；本机预约取消和本机创建/已结束预约删除均需经过页面内确认，确认框支持 Escape、Tab 焦点循环和关闭后的焦点恢复；删除确认后同步移除会议历史、IndexedDB 录制和按会议号保存的报告待办，静态演示会议保持只读。 | 已实现 |
| REQ-010 | 用户可以查找、查看和管理课堂回放。 | 回放页面展示课程、时长、字幕和观看状态；已结束且有本地录制的本机创建/预约会议会进入回放列表；本地回放支持按会议号恢复真实 Blob、播放、下载和复制本地引用，媒体缺失时只显示元数据降级提示；回放查看区支持显式关闭和 Escape 关闭，关闭后恢复播放、预览或详情入口焦点；本地发布标记会反馈保存结果，并在同源窗口间同步；恢复本机发布标记时同时限制存储原始字符串和规范化标题长度，超限或未知标题按未发布处理。 | 已实现 |
| REQ-011 | 用户可以集中管理会议与课程产生的资料。 | 资料页面展示分类、当前页面文件数量、最近文件和本地预览入口；详情与预览保持同一资料上下文，切换资料时清理旧预览，Escape 先关闭预览再关闭详情，关闭后分别恢复预览或详情入口焦点；当前页面上传资料可下载原文件，图片、视频和音频使用真实本地对象 URL 预览，并可移除；上传后的本地资料元数据会进入全局搜索并按稳定资料标识精确定位到详情（同名资料也不会误选）；支持 IndexedDB 的浏览器刷新后会按资料 ID 恢复文件内容，不支持或持久化失败时只恢复元数据，不伪造原文件内容；空文件名或超过 160 个字符的原始文件名会被拒绝，静态演示资料保持只读；本地资料在缺少 `crypto.randomUUID` 时仍能生成页面标识；资料元数据删除或同源 storage 更新会清理内存和 IndexedDB 孤儿内容；真实云端容量不在本地原型范围。 | 已实现 |
| REQ-012 | 预约会议后，本机刷新页面仍保留预约结果。 | 本地状态保存并在我的会议中展示；写入后回读失败时保留当前表单/预约并明确提示未保存；异常超大本地载荷、展示元数据、原始字符串长度和超出 6–18 位范围的房间号安全回退，只有缺少房间号的旧记录使用兼容默认值。 | 已实现 |
| REQ-013 | 用户可以授权浏览器采集真实摄像头与麦克风。 | 本地会议页显示真实预览并处理权限失败；连续设备切换只提交最后请求，已提交后变为过期的发送轨道会恢复为当前有效轨道，发送器替换随后失败时也会回滚。 | 已实现 |
| REQ-014 | 两个同源本地窗口可通过相同房间号建立点对点连接。 | BroadcastChannel 完成信令，RTCPeerConnection 进入 connected；信令按当前会话串行处理，重复 offer/answer 不会重复推进协商；异常或超大信令在交给 WebRTC 前被丢弃；远端描述到达前暂存的 ICE 只归属其发送方且最多保留 128 条；聊天频道复用 6–18 位房间号边界；每次入会轮换 peer 标识，离会重入后旧 peer 回调和信令不会污染新会话；缺少 `crypto.randomUUID` 时仍可生成本地标识。 | 已实现 |
| REQ-015 | 静音和关闭视频直接作用于本地媒体轨道。 | 对应 MediaStreamTrack 的 enabled 状态变化；设备切换等待期间的最后一次开关操作也会应用到替代轨道。 | 已实现 |
| REQ-016 | 用户可以共享屏幕并恢复摄像头画面。 | getDisplayMedia 与 replaceTrack 完成轨道切换；等待对方加入时先共享，建立 peer 后也会发送屏幕轨道；开始或停止共享的发送器替换失败时回滚到仍有效的摄像头或屏幕轨道；共享期间关闭摄像头仍保留共享预览。 | 已实现 |
| REQ-017 | 用户可以在会议中切换摄像头和麦克风。 | 新设备轨道替换当前发送轨道；替换已提交后失败时回滚到旧轨道；过期设备枚举结果不会覆盖当前设备选择。 | 已实现 |
| REQ-018 | 本地实验明确说明只能在同源浏览器窗口间使用。 | 入会界面和项目文档标明边界。 | 已实现 |
| REQ-019 | 本地会议核心流程具有不依赖真实浏览器设备的自动化回归测试。 | 测试脚本使用可控的媒体、信令和 WebRTC 模拟环境，覆盖主要成功与失败路径。 | 已实现 |
