# 产品需求

| 编号 | 需求 | 验收证据 | 状态 |
| --- | --- | --- | --- |
| REQ-001 | 用户可以快速发起、预约或通过会议号加入会议。 | 首页原型可完成三种入口交互。 | 已实现 |
| REQ-002 | 课程课堂可以关联课程与班级，并自动生成参会范围。 | 创建课堂面板展示课程、班级和人数。 | 已实现 |
| REQ-003 | 会中提供麦克风、摄像头、共享、录制、成员和聊天控制。 | 会议控制台可操作并显示状态反馈。 | 已实现 |
| REQ-004 | 主持人可以发起签到、投票、测验和随机选人。 | 教学互动面板可切换并发布示例活动。 | 已实现 |
| REQ-005 | 会中能识别已到、迟到和未到成员。 | 成员面板按状态展示班级名单。 | 已实现 |
| REQ-006 | 会后形成出勤、参与、互动、录制和待办报告。 | 课后报告页展示各维度摘要。 | 已实现 |
| REQ-007 | 手机和桌面端均能完成主要流程。 | 响应式布局在常见宽度下可用。 | 已实现 |
| REQ-008 | 第一版明确说明音视频为交互原型，不伪装为生产通信服务。 | 产品界面和任务记录标注原型边界。 | 已实现 |
| REQ-009 | 用户可以集中查看即将开始、已结束和由自己创建的会议。 | 我的会议页面支持状态分组和主要操作。 | 已实现 |
| REQ-010 | 用户可以查找、查看和管理课堂回放。 | 回放页面展示课程、时长、字幕和观看状态。 | 已实现 |
| REQ-011 | 用户可以集中管理会议与课程产生的资料。 | 资料页面展示分类、容量和最近文件。 | 已实现 |
| REQ-012 | 预约会议后，本机刷新页面仍保留预约结果。 | 本地状态保存并在我的会议中展示。 | 已实现 |

## 状态约定

需求状态使用：`待确认`、`已确认`、`已实现`、`已废弃`、`已拒绝`。
