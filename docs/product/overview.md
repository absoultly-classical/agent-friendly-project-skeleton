# 产品概览

## 产品名称

暂定名：学习通会议。

## 要解决的问题

学习通已有课程、班级、通讯录、教学活动和学习数据，泛雅课堂也能支撑在线教学，
但用户在教研会、答辩、培训、家长会、行政会议和跨班授课等场景中，仍需要在多个
产品之间切换，重复邀请成员、核对身份、整理材料和沉淀会后结果。

学习通会议要提供一套学习通内原生的音视频协作入口：既具备通用会议能力，又能在
课堂模式下直接使用课程班级、教学活动、成绩和课堂报告。

## 用户

- 教师：发起课程课堂、答辩、教研或临时会议，并完成教学互动与课后复盘。
- 学生：从学习通直接进入课堂或会议，参与音视频、讨论和教学活动。
- 学校管理者：组织培训与行政会议，掌握出席情况和会议资料。
- 校外参与者：通过邀请链接或会议号，在受控权限下临时参会。

## 目标

- 用户不离开学习通即可预约、加入和管理会议。
- 创建课程课堂时自动带入课程、班级和师生身份。
- 会中同时支持通用协作与签到、投票、测验等教学活动。
- 会后自动形成出勤、互动、录制、资料和待办汇总。
- 核心流程在手机和桌面浏览器中均可完成。

## 非目标

- 本地实验版不提供跨设备信令、媒体服务器、TURN 中继和生产级录制。
- 第一版不替代课程建设、作业、考试或完整教务系统。
- 第一版不支持大型公开直播和万人会议。

## 成功信号

- 教师可在一分钟内从课程创建一场课堂并邀请全班。
- 学生从首页进入进行中课堂不超过两次操作。
- 会中可完成成员管理、聊天、屏幕共享和至少三类教学互动。
- 会后报告能回答谁参加、参与多久、做了什么和下一步是什么。
