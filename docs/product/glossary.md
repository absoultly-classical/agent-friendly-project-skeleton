# 领域词汇表

| 术语 | 准确定义 | 易混淆项或备注 |
| --- | --- | --- |
| 会议模式 | 当前会议的产品语义，取值为“课程课堂”或“普通会议”；它决定成员范围、互动入口和报告文案。 | 不等同于 WebRTC 的连接状态；不使用“房间类型”替代。 |
| 本机会议历史 | 当前浏览器页面所在设备保存的会议记录，包含本机创建会议或本机预约的展示元数据和可选报告快照。 | 不代表服务端权威历史；不等同于所有参会者共享的会议记录。 |
| 本地 WebRTC 实验 | 在同源浏览器窗口之间使用真实媒体设备、BroadcastChannel 和 RTCPeerConnection 的本地原型能力。 | 不是生产会议服务，不提供跨设备信令、鉴权、TURN 或云端录制。 |
| 同源窗口 | 协议、主机和端口均相同的浏览器窗口；本地聊天和 WebRTC 实验仅在此边界内通信。 | 不等同于同一设备或同一用户；同源本身不提供身份认证。 |
| 会话报告快照 | 会议结束时由当前页面记录的时长、参与窗口、聊天数量、已发布活动和录制开关状态。 | 只描述本地原型会话；录制 Blob 是否可恢复由本机 IndexedDB 和会议号关联决定，不是服务端报告。 |
| 本机会议录制 | 与会议号关联、用于历史报告预览和下载的本地 WebM Blob。 | 仅同一浏览器本机尽力持久化；不等同于云端录制、权限控制或跨设备回放。 |
| 会议号 | 用于本地实验频道和页面导航的 6–18 位数字标识；输入中的空格和短横线可被归一化。 | 不承担权限、身份认证或跨设备路由；不要与会议 ID 混用。 |
| 会议资料 | 会议或课程相关的文件元数据条目，包含名称、来源、大小、目录和更新时间；本地上传条目可关联本机文件内容。 | 静态演示资料只读；本地上传内容在当前页面保留，并在支持 IndexedDB 时可跨刷新恢复；不代表云端资料。 |
| 本地资料内容 | 与本地上传资料 ID 关联、用于预览和下载的本机 `File` 内容。 | 当前页面内存优先；IndexedDB 只做同一浏览器的尽力持久化，不提供账号、权限或跨设备同步。 |
| 资料详情 | 用户从资料列表选中某一条后看到的元数据上下文。 | 与“资料预览”不同；关闭详情会同时清理当前预览。 |
| 资料预览 | 当前选中资料的类型化本地查看区域；本地图片、视频和音频可使用真实 `File` 内容预览。 | 不等同于回放播放器；静态演示文档仍是占位查看；切换资料会清理旧预览。 |
| 本地发布标记 | 当前设备对已知演示回放标题保存的发布状态。 | 不是服务端发布，也不授予其他用户访问权限。 |

需求、接口、代码、测试和任务文档应使用同一套词汇。两个合理的读者可能产生不同
理解时，就应补充或澄清这个术语。
