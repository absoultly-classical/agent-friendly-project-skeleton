# 0107：本机报告生成状态持久化

- 状态：已完成

- 关联需求：REQ-006、REQ-012
- 关联决策：无

## 目标

让本机快速会议关闭自动报告、手动生成和刷新恢复的状态保持一致。

## 范围

### 包含

- 在本机会议记录中保存报告是否已生成。
- 历史报告打开时恢复记录中的生成状态。
- 手动生成历史本机报告后更新对应记录，而不是默认房间。
- 补充刷新前后状态回归测试并更新架构说明。

### 不包含

- 不实现服务端报告任务、云端报告或跨设备同步。
- 不改变静态历史报告和主动加入会议的演示语义。

## 计划

- [x] 审计创建选项、结束报告和本机历史恢复的状态链路。
- [x] 持久化自动/手动报告生成状态并隔离历史房间上下文。
- [x] 补充刷新恢复测试并运行页面回归。
- [x] 完成全量门禁、归档记录并继续下一轮审计。

## 验收标准

- [x] 关闭自动生成报告的本机会议，刷新后历史报告仍显示“立即生成报告”。
- [x] 手动生成后，本机记录保存已生成状态，刷新后可恢复本地会话报告。
- [x] 更新状态使用历史记录的房间号，不会误写默认房间或其他会议。
- [x] 全量测试、类型检查、构建、Lint、diff 和 HTTP 检查通过。
