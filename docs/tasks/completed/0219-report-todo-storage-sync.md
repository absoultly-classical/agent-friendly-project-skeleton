# 0219：报告待办同源窗口同步

- 状态：已完成
- 负责人：Codex
- 创建日期：2026-08-30
- 关联需求：REQ-006

## 目标

让同源其他窗口对同一会议报告待办的修改及时反映到当前报告页，保持本机报告状态一致。

## 实现记录

- 抽取默认待办与本机已保存待办的合并逻辑，避免初始化和跨窗口恢复出现两套规则。
- 报告页监听 `learning-meeting-report-todos:{roomId}` 的 `storage` 事件，支持勾选、新增和清空本机存储后的恢复。
- 继续区分本地报告和静态演示报告，静态报告不写入本机待办。

## 验收标准

- [x] 当前窗口首次打开报告时能恢复对应会议号的待办状态。
- [x] 同源窗口更新同一会议待办后，当前报告同步完成状态和新增任务。
- [x] 静态演示报告仍不创建本机待办键。
- [x] 不影响现有待办写入边界和删除会议时的待办清理。
