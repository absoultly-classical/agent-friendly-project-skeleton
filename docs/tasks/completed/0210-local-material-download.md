# 0210：本地资料原文件下载

- 状态：已完成
- 负责人：Codex
- 创建日期：2026-08-30
- 关联需求：REQ-011

## 目标

补齐本地资料上传后的可用闭环，让用户可以在当前页面取回原文件，同时准确区分刷新后仍存在的元数据和已经释放的文件内容。

## 实现记录

- 在资料页面内存中关联当前页上传的 `File` 对象，并增加“下载原文件”操作；图片、视频和音频可使用对象 URL 真实预览。
- 下载使用临时 Blob URL，完成后立即释放 URL；静态演示资料仍不提供下载。
- 刷新或重新挂载后只恢复本地资料元数据，点击下载会明确提示重新上传文件内容。
- 更新资料页说明、README、需求和架构文档，避免暗示已接入云盘。

## 验收标准

- [x] 当前页面上传的文件可以按原文件名下载。
- [x] 当前页面上传的图片、视频和音频可以预览，关闭预览后释放对象 URL。
- [x] 下载失败或文件内容已释放时显示明确反馈，不伪造下载成功。
- [x] 刷新后元数据仍可检索和查看，文件内容缺失时不会生成空下载。
- [x] 静态演示资料保持只读和不可下载边界。
