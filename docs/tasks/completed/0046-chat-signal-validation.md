## 目标

让本地聊天频道对格式错误的同源消息保持容错，不因非字符串发送者名称导致接收页面抛异常或中断后续聊天。

## 范围

### 包含

- 对 `senderName` 做显式字符串检查和空白回退。
- 保持合法自定义名称的正常显示。
- 使用 fake BroadcastChannel 注入畸形消息并验证页面继续可用。

### 不包含

- 不实现服务端 schema 校验、鉴权或消息持久化。
- 不改变聊天频道协议的核心字段。
- 不使用浏览器自动化验证。

## 约束与假设

- 约束：畸形 `senderName` 不能让消息处理器抛出异常。
- 约束：空白或缺失名称显示为“远端参会者”。
- 假设：同源 BroadcastChannel 是本地实验中的不可信输入边界。
