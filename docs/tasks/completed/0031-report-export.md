## 目标

让课堂报告的“导出报告”按钮生成可下载的本地文本报告，而不是只显示提示，从而让报告摘要具备可带走的交付结果。

## 范围

### 包含

- 根据当前报告标题和固定演示统计生成文本文件。
- 使用浏览器下载 API 创建并释放临时对象 URL。
- 下载 API 不可用时提供明确失败提示。
- 使用 jsdom 验证文件内容、下载属性和 URL 清理。

### 不包含

- 不生成服务端 PDF、真实云盘文件或复杂排版文档。
- 不改变报告中的演示统计来源。

## 必读上下文

- `docs/product/overview.md`
- `docs/architecture/overview.md`
- `docs/development.md`
- `web/app/page.tsx`
- `web/app/page.test.tsx`

## 约束与假设

- 约束：导出内容必须明确标注为当前报告摘要，避免暗示服务端生成的正式文件。
- 约束：对象 URL 使用后必须释放，避免重复导出造成资源泄漏。
- 假设：jsdom 中 mock `URL.createObjectURL`、`revokeObjectURL` 和点击行为足以验证下载流程。
