## 目标

让会中页标题准确表达本地 WebRTC 当前阶段，区分尚未入会、入会等待、已连接、连接异常和主动离会。

## 范围

### 包含

- 会中标题根据 `idle`、`starting`、`waiting`、`connecting`、`connected` 和 `error` 显示对应状态。
- 保留现有独立连接状态指示和错误操作入口。
- 补充页面回归测试，覆盖大厅和离会后的标题状态。

### 不包含

- 不改变 WebRTC 协商状态机或服务端信令。
- 不把本地连接状态扩展为云端会议状态。

## 计划

- [x] 对比会中标题、连接状态指示和离会后的实际状态。
- [x] 修改状态文案并补充回归测试。
- [x] 运行门禁、更新架构记录并归档。

## 验收标准

- [x] 尚未入会时不显示“进行中”。
- [x] 已连接时显示“进行中”，离会后回到大厅语义。
- [x] 连接异常时标题明确提示异常。
- [x] 页面测试、类型检查、构建、Lint 和 HTTP 检查通过。
