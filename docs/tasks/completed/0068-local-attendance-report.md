# 0068：让当前会话报告出勤与本地参与者一致

## 目标

修正当前本地 WebRTC 会话结束后报告仍显示课程固定出勤数据的问题，让报告中的参与者数量和明细符合本地会话实际状态。

## 范围

- 当前会话快照记录本地窗口和远端窗口是否加入。
- 当前会话报告显示本地会话参与数（0–2 个窗口）。
- 当前会话出勤明细只显示本地窗口/远端窗口状态，不显示课程静态名单。
- 历史会议报告继续使用课程演示出勤摘要和名单。
- 导出当前会话报告时包含本地参与数。

## 验收标准

- [x] 未开启设备结束当前会话时，报告显示 0/2 个本地窗口参与。
- [x] 仅本地窗口加入时，报告显示 1/2，并在明细中标记本地窗口已加入。
- [x] 有远端窗口时，报告显示 2/2，并在明细中标记远端窗口已加入。
- [x] 历史会议报告仍显示课程演示出勤数据和名单。
- [x] 补充 jsdom 自动化测试，并通过 test、typecheck、lint、build。

## 验证记录

2026-08-29：完成当前本地会话报告出勤快照，按本地/远端窗口参与状态显示 0/2、1/2 或 2/2，并保留历史会议的演示名单；新增 jsdom 回归覆盖。`npm run check` 通过（2 个测试文件、92 项测试，typecheck 和 build 通过），`npm run lint` 通过，`git diff --check` 通过（仅有换行符提示）。

## 风险与边界

本地会话无法推断真实课程出勤、姓名和班级名单；远端窗口只显示为远端参会者，真实身份和出勤服务需后续接入。
