# 0098：屏幕共享的视频轨道前置条件

- 状态：已完成

- 关联需求：REQ-003、REQ-016、REQ-017、REQ-019

## 目标

避免用户在未采集视频轨道时看到可用的屏幕共享入口，却因 peer 没有视频发送轨道而产生无效共享。

## 范围

### 包含

- 没有 live 视频轨道时禁用会议页屏幕共享按钮。
- hook 直接调用共享时也拒绝无视频轨道，并保持未共享状态。
- 补充页面和 hook 回归测试。

### 不包含

- 不实现无摄像头入会时动态添加视频 transceiver。
- 不改变关闭摄像头轨道后的恢复、切换设备和共享错误流程。

## 计划

- [x] 增加视频轨道前置条件并补测试。
- [x] 更新架构说明，运行完整门禁并归档。

## 验收标准

- [x] 关闭摄像头入会时屏幕共享按钮不可用。
- [x] 直接调用共享 API 时不会请求屏幕或标记为共享成功。
- [x] 有 live 视频轨道时既有屏幕共享行为不受影响。
- [x] 相关测试、类型检查、Lint、构建和 diff 检查通过。
