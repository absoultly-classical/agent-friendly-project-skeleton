## 目标

让创建和加入会议弹窗支持键盘关闭，并在打开时把焦点放到关闭按钮，提升主要会议入口
在键盘和辅助技术场景下的可达性。

### 包含

- 弹窗打开后自动聚焦关闭按钮。
- 在弹窗内按 Esc 关闭。
- 增加 jsdom 键盘交互回归测试。

### 不包含

- 完整焦点陷阱、浏览器原生辅助技术兼容性和视觉回归测试。
- 浏览器测试。
