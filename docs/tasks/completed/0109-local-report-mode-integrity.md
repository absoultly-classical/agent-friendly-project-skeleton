## 目标

防止本机会议记录与报告快照的模式字段冲突，避免普通会议恢复成课堂报告。

## 范围

### 包含

- 读取本机记录时校验报告快照模式与会议记录模式一致。
- 冲突快照按无本地快照处理，沿用会议记录模式的演示报告。
- 补充篡改/旧数据回归测试并更新架构说明。

### 不包含

- 不引入签名、鉴权或服务端报告校验。
- 不改变合法本机报告快照的统计和展示。

## 计划

- [x] 审计本机记录和报告快照的模式恢复链路。
- [x] 收紧模式一致性并补异常数据测试。
- [x] 运行完整门禁、归档记录并继续下一轮审计。

## 验收标准

- [x] 普通会议记录携带课堂快照时不会显示本地课堂报告。
- [x] 冲突数据不会污染原始记录，页面回退到记录模式的演示报告。
- [x] 全量测试、类型检查、构建、Lint、diff 和 HTTP 检查通过。

- 2026-08-30：读取记录时以记录模式为准，冲突快照不再进入 `LocalMeetingRecord`，并新增普通会议回退测试。
