## 目标

交付一个可运行、可部署的学习通会议 Web 原型，验证“通用会议能力 + 课程教学增强”
的产品方向。

## 范围

### 已完成

- 会议大厅、快速会议、预约会议和加入会议。
- 课程课堂模式、课程与班级关联。
- 会中视频宫格、基础控制、成员、聊天和教学互动。
- 课后报告、响应式布局和私有部署。

### 未包含

- 真实摄像头、麦克风、屏幕采集和音视频传输。
- 真实账号、课程、班级、消息、录制与云盘接口。
- 生产级权限、安全、计费和大规模并发。

## 验收结果

- [x] 用户能从首页进入创建、加入和进行中会议流程。
- [x] 会中基础控制和教学互动具有可见状态反馈。
- [x] 用户能查看成员状态、聊天和课后报告。
- [x] 桌面与手机宽度均有响应式布局。
- [x] 项目文档与原型能力一致。
