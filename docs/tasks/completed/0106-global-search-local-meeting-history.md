# 0106：全局搜索接入本机会议历史

- 状态：已完成

- 关联需求：REQ-009、REQ-012

## 目标

让本机创建的快速会议历史进入全局搜索，并能定位到会议中心的正确状态列表。

## 范围

### 包含

- 将本机创建会议记录加入全局搜索索引。
- 与本机预约和静态会议按会议号去重。
- 搜索已结束本机会议时自动展示“已结束”列表。
- 补充搜索定位回归测试并更新架构说明。

### 不包含

- 不实现服务端搜索、云端历史或跨设备同步。
- 不改变本机会议记录的存储格式和保留数量。

## 计划

- [x] 审计搜索目录、本机历史记录和会议中心定位入口。
- [x] 接入本机会议搜索结果并按状态定位会议中心。
- [x] 运行页面回归、全量门禁、Lint、diff 和 HTTP 检查。
- [x] 完成记录归档，并继续下一轮缺口审计。

## 验收标准

- [x] 创建并结束快速会议后，可在全局搜索中按标题找到该会议。
- [x] 点击搜索结果进入“我的会议”，已结束记录自动显示在“已结束”标签。
- [x] 搜索结果不会因会议号与其他已知会议重复而重复展示。
- [x] 相关验证通过，任务记录与实际代码一致。
