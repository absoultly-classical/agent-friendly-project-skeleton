## 目标

避免本地存储 API 静默丢弃写入时界面误报成功，保证预约、会议历史和回放发布状态只有在写入后可回读时才视为已保存。

## 完成内容

- `setItem` 成功后立即回读并比对预约、会议历史和回放发布标记。
- `removeItem` 后确认对应键已不存在；静默删除失败时保留预约。
- 增加 Storage fake 静默丢弃写入/删除的页面回归测试。
- 更新架构与需求记录，明确本地存储持久化边界。

## 影响与边界

本地存储仍然只是当前设备上的原型数据，不引入服务端数据库或跨设备同步。写入校验增加一次本地读取；存储实现静默失败时，页面会提示失败而不会伪造已保存状态。
