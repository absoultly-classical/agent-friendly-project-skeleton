## 目标

让通知中心的已读操作在刷新后保持一致，并能反映同源窗口中的最新状态。

## 实现记录

- 使用白名单通知 ID 保存已读列表，限制载荷大小并在写入后回读验证。
- 点击单条通知或“全部已读”后同步保存本机状态；写入失败仍更新当前页面并展示提示。
- 监听同源 `storage` 事件，其他窗口更新或清空已读状态时刷新通知角标与列表。
- 新增全部已读持久化、重新挂载恢复和同源同步回归测试。
