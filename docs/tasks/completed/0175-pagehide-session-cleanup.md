## 目标

页面关闭或离开时主动结束本地 WebRTC 会话，减少同源对端残留连接状态和媒体资源泄漏。

## 范围

### 包含

- 监听 `pagehide` 并复用既有 `leave()` 清理路径。
- 页面进入 BFCache 时不误发离会，保留会话暂存语义。
- 增加页面离开后的本地媒体和状态清理测试。

### 不包含

- 不提供跨设备后台连接保持能力。
- 不引入浏览器自动化测试或服务端会话。

## 实现记录

- 2026-08-30：发现页面卸载路径只依赖 React 清理，且不通知同源对端。
- 2026-08-30：增加非 BFCache `pagehide` 处理并复用 `leave()`；BFCache 事件保持连接。
- 2026-08-30：新增页面离开清理回归测试。
