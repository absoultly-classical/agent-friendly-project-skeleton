# 0153：本地会议元数据边界

- 状态：已完成
- 负责人：Codex
- 创建日期：2026-08-30
- 关联需求：REQ-009、REQ-012

## 目标

本机会议历史和预约恢复时，除主题、房间号和总载荷外，对用于列表、搜索和报告入口的
元数据执行统一长度与非空校验，避免异常本地数据污染页面展示。

## 计划

- [x] 审计本机历史和预约恢复字段的边界差异。
- [x] 增加统一的会议元数据字段校验和记录数量上限。
- [x] 补充历史、预约异常元数据回归测试。
- [x] 运行门禁、更新架构记录并归档。

## 验收标准

- [x] 异常或超长会议元数据不会恢复到会议列表或全局搜索。
- [x] 合法历史、预约、旧格式兼容和报告入口行为不回退。
- [x] 本地历史恢复最多处理保留数量范围内的记录。
- [x] 测试、类型检查、构建、Lint 和 HTTP 检查通过。

## 工作记录

- 2026-08-30：发现本机历史和预约恢复只校验主题、房间号及部分字段类型，展示元数据仍可被异常载荷无限拉长。
- 2026-08-30：增加统一的 ID、日期、月份、时间、详情、类型和视觉标记边界；历史解析在 `slice` 后最多恢复 20 条。
- 2026-08-30：补充异常元数据与 21 条历史恢复回归测试，完成全量门禁。
