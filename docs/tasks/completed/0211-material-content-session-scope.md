# 0211：资料内容的单页会话边界

- 状态：已完成
- 负责人：Codex
- 创建日期：2026-08-30
- 关联需求：REQ-011

## 目标

让当前页上传的文件内容在单页应用内部导航时保持可用，避免用户切换到首页再返回资料页后只能看到元数据。

## 实现记录

- 将当前页上传的 `File` 内容缓存从资料组件提升到 `Home` 的单页会话状态。
- 资料页卸载后重新挂载仍可预览和下载同一会话内的文件内容。
- 刷新或关闭页面仍不会恢复文件内容；本机存储继续只保存经过校验的资料元数据。
- 新增跨页面导航回归测试并同步更新架构说明。

## 验收标准

- [x] 资料页与首页之间导航不会丢失当前会话文件内容。
- [x] 刷新后只有元数据时不会伪造原文件或下载成功。
- [x] 对象 URL 预览仍在关闭时释放。
- [x] 相关自动化验证通过。
