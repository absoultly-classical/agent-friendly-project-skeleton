## 目标

让报告导出的文本摘要与页面当前报告模式保持一致，避免历史普通会议导出为课堂报告，或把普通会议的统计写成课程出勤数据。

## 范围

### 包含

- 导出函数接收报告模式。
- 普通会议历史报告导出通用参会、会议互动和会议消息语义。
- 课程历史报告保留课程出勤和互动统计。
- 当前本地会话导出继续使用本地快照数据和本地边界说明。
- 补充导出回归测试和架构说明。

### 不包含

- 不接入服务端报告、真实文件存储或云端导出任务。
- 不改变报告页面其他交互和历史演示数据来源。

## 约束与假设

- 约束：导出内容目前由当前页面生成 Blob，不代表服务端文件。
- 约束：历史报告没有完整服务端快照，只能根据列表项模式输出对应演示统计。
- 假设：为导出函数增加显式模式参数，比从标题推断会议类型更可靠；通过页面测试拦截 Blob 和下载链接验证。
