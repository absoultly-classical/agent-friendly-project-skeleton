# 0181：限制回放发布标记的原始存储长度

- 状态：已完成

- 更新日期：2026-08-30
- 关联需求：REQ-010
- 关联决策：无

## 目标

避免本机回放发布标记通过大量首尾空白绕过 512 个字符的存储边界，防止异常本地数据进入回放页面状态。

## 范围

### 包含

- 读取回放发布标记时先校验存储原始字符串长度。
- 保留规范化标题长度校验和已知回放标题白名单校验。
- 超限的本机值按未发布处理，不显示虚假的已发布状态。
- 增加原始长度边界回归测试并同步产品、架构说明。

### 不包含

- 不改变回放目录、发布按钮行为或真实服务端发布能力。
- 不清理用户本机其他 localStorage 数据。
