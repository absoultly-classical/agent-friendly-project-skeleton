## 目标

让会中发布的课堂活动结果进入会后报告，确保教师在结束会议后仍能确认本次会中实际发布了哪些互动活动。

## 范围

### 包含

- 在首页会话状态中记录已发布的活动类型，避免重复记录。
- 会中活动面板反映每个活动是否已发布。
- 会后报告显示本次会话发布的活动名称。
- 使用 jsdom 验证发布、切换和结束会议后的状态连续性。

### 不包含

- 不接入真实课堂活动服务、成绩系统或远端参与结果。
- 不修改报告中已有的演示统计数值。

- `docs/development.md`

- `web/app/page.test.tsx`

## 约束与假设

- 约束：活动发布记录只保留在当前前端会话，离开页面后不持久化。
- 约束：同一活动重复点击发布不能在报告中产生重复名称。
- 假设：报告显示已发布活动名称即可证明本地状态连续性，通过 jsdom 测试确认。
