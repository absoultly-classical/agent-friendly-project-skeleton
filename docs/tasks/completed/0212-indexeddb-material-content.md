# 0212：IndexedDB 资料内容持久化

- 状态：已完成
- 负责人：Codex
- 创建日期：2026-08-30
- 关联需求：REQ-011

## 目标

让本地上传资料在支持 IndexedDB 的同一浏览器刷新后仍可预览和下载，同时保持本地原型不冒充云端同步。

## 实现记录

- 新增按资料稳定 ID 存取 `File` 内容的 IndexedDB 适配层。
- 资料页挂载时按当前元数据异步恢复文件内容，当前单页会话内容优先于持久化副本。
- 上传和移除资料时同步更新内存索引，并尽力写入或删除 IndexedDB 内容。
- 资料元数据发生同源 storage 更新时裁剪内存中的 `File` 引用，并清理不再对应资料的 IndexedDB 孤儿记录。
- IndexedDB 不可用或操作失败时保留当前页面可用性，降级为元数据恢复和重新上传提示。

## 验收标准

- [x] 支持 IndexedDB 时可按资料 ID 保存并恢复文件名、类型、修改时间和内容。
- [x] 删除资料和跨窗口元数据清空不会留下可继续下载的孤儿内容。
- [x] IndexedDB 不可用时不影响既有当前页上传、预览和下载流程。
- [x] 不声称已接入云端资料、账号权限或跨设备同步。
- [x] 相关自动化验证通过。
