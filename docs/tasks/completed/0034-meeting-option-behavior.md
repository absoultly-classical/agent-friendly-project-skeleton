## 目标

让创建会议中的“入会自动静音”和“自动生成课堂报告”真正影响后续本地会话，而不是只停留在视觉上的复选框。

## 范围

### 包含

- 创建或预约会议时保存两个选项，并让预约记录兼容旧数据。
- 进入由创建流程产生的会议时，根据自动静音选项设置入会媒体偏好。
- 结束未开启自动报告的会议时显示未生成状态，并允许在报告页手动生成。
- 补充 jsdom 覆盖创建选项、预约恢复和会后状态。

### 不包含

- 不实现服务端录制、报告流水线或远端权限同步。
- 不改变直接输入会议号加入流程的媒体偏好。

## 约束与假设

- 约束：旧版预约 JSON 缺少选项字段时继续可读，并采用默认开启报告、自动静音。
- 约束：选项只影响当前本地原型会话，不宣称已控制真实服务端录制。
- 假设：本地入会大厅的复选框状态和报告未生成状态足以验证行为连续性。
