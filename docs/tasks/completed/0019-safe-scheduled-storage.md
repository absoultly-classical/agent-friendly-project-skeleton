## 目标

让预约记录在本机存储不可用、配额不足或隐私模式限制时保持页面可用，并向用户反馈
预约未保存，而不是让异常中断页面渲染或状态流转。

## 范围

### 包含

- 捕获预约记录读取、写入和删除的存储异常。
- 写入失败时保留弹窗和当前页面状态，并显示明确反馈。
- 删除失败时不提前移除页面中的预约记录。
- 增加 jsdom 异常路径测试。

### 不包含

- 服务端兜底存储、跨设备同步和真实浏览器隐私模式测试。
- 改变当前本地 JSON 数据结构。

## 约束与假设

- 约束：本机存储仍是演示级数据源，异常时不能伪装为已同步。
- 约束：不使用浏览器测试，使用可控的 jsdom localStorage 异常模拟。
- 假设：后续接入服务端后，当前失败反馈可替换为服务端错误和重试策略。
