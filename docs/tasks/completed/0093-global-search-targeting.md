## 目标

让全局搜索的回放和资料结果真正打开对应条目，避免“已定位”只切换页面而没有呈现目标内容。

## 范围

### 包含

- 搜索回放结果后打开对应回放查看器。
- 搜索资料结果后打开对应资料详情。
- 支持当前已经位于目标页面时仍能更新选中条目。
- 补充回放、资料搜索定位回归测试。

### 不包含

- 不扩展服务端搜索、全文索引或云端资产权限。
- 不把未纳入当前索引的临时上传资料暴露到全局搜索。

## 约束与假设

- 约束：搜索结果来自前端已知的静态演示目录和当前本机预约。
- 约束：回放/资料目标不存在时不能伪造内容，应维持既有页面边界。
- 假设：通过 Home 传递目标名称，并由目标页面响应 prop 变化即可覆盖跨页面和同页定位。
