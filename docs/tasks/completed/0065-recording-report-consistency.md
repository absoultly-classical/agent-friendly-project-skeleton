# 0065：修正录制状态与课后报告一致性

## 目标

让会中录制状态和课后报告的回放展示保持一致，避免未开启录制时报告仍声称录制已保存。

## 范围

- 记录当前会议是否曾真正开启过录制。
- 结束会议后将录制状态传递给报告页。
- 未开启录制时报告显示明确的未录制状态，不提供虚假的回放播放器或复制链接。
- 开启过录制时保留现有回放查看与分享能力。
- 进入新会议时清除上一场会议的录制记录。

## 验收标准

- [x] 未开启录制结束会议时，报告显示“本次会议未开启录制”。
- [x] 未录制报告不显示打开回放、复制回放链接等动作。
- [x] 开启过录制后结束会议，报告显示回放并可打开播放器、复制链接。
- [x] 新会议不继承上一场会议的录制记录。
- [x] 补充 jsdom 自动化测试，并通过 test、typecheck、lint、build。

## 验证记录

2026-08-29：完成会中录制历史状态、报告回放条件渲染和无录制待办语义；补充未录制、已录制和停止后保留状态测试。`npm run check` 通过（2 个测试文件、90 项测试，typecheck 和 build 通过），`npm run lint` 通过，`git diff --check` 通过（仅有换行符提示）。

## 风险与边界

当前录制仍是本地 UI 状态，不接入 MediaRecorder、云端转码、存储或真实回放媒体；报告只表达当前原型已记录过“开启录制”这一事实。
