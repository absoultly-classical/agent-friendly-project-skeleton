## 目标

让预约会议历史报告的手动生成状态在当前页面和刷新后保持一致。

## 范围

### 包含

- 手动生成预约历史报告时更新预约本机记录。
- 按预约房间号更新目标，避免影响快速会议或默认房间。
- 补充预约报告生成后的重挂载回归。

### 不包含

- 不实现服务端报告生成任务或云端状态同步。
- 不改变报告快照和既有预约结束态。
