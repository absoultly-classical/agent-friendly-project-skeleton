## 目标

让会议模式、课堂互动类型和会议中心状态筛选的视觉选择同步暴露给辅助技术，避免用户只能通过颜色或布局判断当前选择。

## 范围

### 包含

- 为会议模式和课堂互动选择按钮增加 `aria-pressed`。
- 为会议中心“即将开始/已结束”筛选按钮增加 `aria-pressed`。
- 增加页面回归测试覆盖状态切换。

### 不包含

- 不改变已有选择、导航或会议业务逻辑。
- 不把这些独立切换控件改造成新的路由或持久化状态。
- 不使用浏览器自动化测试。

## 实现记录

- 2026-08-30：审计发现几组选择按钮仅通过 `active` CSS 类表达状态。
- 2026-08-30：同步添加 `aria-pressed`，并用页面测试验证切换前后状态。
