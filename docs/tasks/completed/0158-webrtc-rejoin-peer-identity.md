# 0158：WebRTC 重入 peer 身份隔离

- 状态：已完成
- 负责人：Codex
- 创建日期：2026-08-30
- 关联需求：REQ-014

## 目标

每次本地 WebRTC 入会都使用新的 peer 标识，避免同一页面离会后快速重入相同房间时，
旧信令中的离会、候选或协商消息与新会话混淆。

## 计划

- [x] 审计 peer ID 生命周期与重入清理路径。
- [x] 在每次新入会操作开始时轮换 peer ID。
- [x] 补充离会重入时 peer 标识变化回归测试。
- [x] 运行门禁、更新架构记录并归档。

## 验收标准

- [x] 同一 hook 离会重入后使用不同 peer ID。
- [x] 旧会话回调和信令不会污染新会话。
- [x] 正常双窗口协商、离会和重新加入行为不回退。
- [x] 测试、类型检查、构建、Lint 和 HTTP 检查通过。

## 工作记录

- 2026-08-30：发现 peer ID 在 hook 生命周期内固定，离会重入相同房间时旧信令可能与新会话共享身份。
- 2026-08-30：在每次新入会清理后轮换 peer ID，旧会话仍先使用旧 ID 发送离会通知。
- 2026-08-30：补充 hello 消息身份轮换回归测试，完成全量门禁。
