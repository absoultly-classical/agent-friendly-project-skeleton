## 目标

让同名本地资料在全局搜索中仍能定位到用户实际点击的那一条记录。

## 实现记录

- 全局搜索资料结果携带稳定的 `materialId`，静态资料和本地资料使用各自记录 ID。
- 会议资料页优先按 ID 恢复详情，只有缺少 ID 时才按文件名兼容定位。
- 页面导航 key 同时包含资料 ID，连续打开同名资料时会刷新正确的详情上下文。
- 新增两个同名资料、不同元数据的精确定位回归场景。
