# 0213：本机录制持久化与会议隔离

- 状态：已完成
- 负责人：Codex
- 创建日期：2026-08-30
- 关联需求：REQ-003、REQ-006

## 目标

让本地录制不再只依赖当前 React 内存，并确保历史报告只读取对应会议的录制内容。

## 实现记录

- 新增按 6–18 位会议号存取本地 WebM Blob 的 IndexedDB 适配层。
- 录制 Blob 生成后异步保存，当前报告优先使用当前会话内存内容。
- 打开本机历史报告时按保存的会议号恢复录制；异步恢复使用序号保护，避免快速切换报告时串档。
- 本机会议记录变化时清理不再属于历史/预约会议的录制条目，IndexedDB 不可用或打开失败时安全降级。
- 更新报告文案，区分“已生成录制”“可恢复本机录制”和静态演示状态。

## 验收标准

- [x] 同一会议号的本机录制可保存、读取和下载。
- [x] 不同会议号的录制内容相互隔离。
- [x] 删除或裁剪本机会议记录后不会保留孤儿录制。
- [x] IndexedDB 不可用或打开失败时不影响当前会话录制。
- [x] 不把本机录制描述成云端录制或跨设备资源。
