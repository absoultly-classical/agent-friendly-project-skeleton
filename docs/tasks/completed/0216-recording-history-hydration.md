# 0216：录制历史恢复与预约回放边界

- 状态：已完成
- 负责人：Codex
- 创建日期：2026-08-30
- 关联需求：REQ-006、REQ-009、REQ-010

## 目标

避免刷新时录制清理任务先于本地会议历史恢复执行，并让已结束的预约会议与本机创建会议拥有一致的回放入口。

## 实现记录

- 本地会议历史恢复完成前不执行录制孤儿清理；恢复后再用当前本机会议和预约会议集合裁剪录制。
- 会议历史或预约存储不可读时跳过录制清理，避免把未知归属的本地媒体误删。
- 将已结束且报告快照标记为有录制的预约会议加入回放列表和全局搜索。
- 使用会议号去重本机创建记录与预约记录，沿用按会议号恢复 Blob 的边界。

## 验收标准

- [x] 刷新恢复历史期间不会以空的初始列表清理录制。
- [x] 本机创建会议和预约会议的本地录制都能进入回放列表。
- [x] 同一会议号不会在回放列表重复出现。
- [x] 既有静态回放和无媒体降级行为保持不变。
