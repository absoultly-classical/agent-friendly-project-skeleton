# 0157：本地资料移除

- 状态：已完成
- 负责人：Codex
- 创建日期：2026-08-30
- 关联需求：REQ-011

## 目标

为当前页面上传的资料元数据提供可逆的页面内移除操作，避免用户只能不断添加资料而
无法整理本地演示目录；静态演示资料保持只读。

## 计划

- [x] 审计资料列表、详情和预览的状态关系。
- [x] 增加仅针对本地上传资料的移除操作。
- [x] 补充移除后列表、详情和预览状态回归测试。
- [x] 运行门禁、更新架构记录并归档。

## 验收标准

- [x] 本地上传资料可以从当前页面资料列表移除。
- [x] 移除时同步关闭对应详情和预览，不影响其他资料。
- [x] 静态演示资料不出现移除操作。
- [x] 测试、类型检查、构建、Lint 和 HTTP 检查通过。

## 工作记录

- 2026-08-30：发现资料页面支持上传、筛选和预览，但上传的当前页面元数据没有移除入口，无法整理临时资料。
- 2026-08-30：新增仅针对 `source === "本地上传"` 的移除操作，移除时清理选中资料和对应预览，静态目录保持只读。
- 2026-08-30：补充上传、打开、移除和静态资料不可移除回归测试，完成全量门禁。
