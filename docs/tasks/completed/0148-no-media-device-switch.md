# 0148：无媒体入会不提供设备切换

- 状态：已完成
- 负责人：Codex
- 创建日期：2026-08-30
- 关联需求：REQ-001、REQ-013、REQ-014、REQ-015、REQ-017

## 目标

纯聊天/旁听入会时不允许通过设备切换控件临时添加媒体轨道，避免本地状态显示已开启
但现有 peer 没有发送器的半连接状态；用户应离开后重新选择媒体入会。

## 计划

- [x] 审计无媒体入会后的设备切换和 peer 发送器状态。
- [x] 禁止无对应 live 轨道的设备切换请求凭空添加媒体。
- [x] 无媒体会话只保留离开操作，隐藏无效的设备选择器。
- [x] 补充 hook 和页面回归测试，运行门禁并归档。

## 验收标准

- [x] 无媒体入会时切换设备不会调用媒体采集或添加轨道。
- [x] 无媒体会话不会显示无效的摄像头/麦克风选择器，但仍可离开连接。
- [x] 正常音频/视频入会的设备切换行为不回退。
- [x] 测试、类型检查、构建、Lint 和 HTTP 检查通过。

## 工作记录

- 2026-08-30：发现空 `MediaStream` 仍触发设备切换器渲染；切换后可添加禁用轨道，但已有 peer 不会自动增加 sender，导致本地状态与远端能力不一致。
- 2026-08-30：设备切换仅允许已有对应 live 轨道的会话，空媒体会话隐藏选择器并保留离开操作；新增 hook 与页面回归覆盖。
- 2026-08-30：完成全量门禁，0148 验收通过。
