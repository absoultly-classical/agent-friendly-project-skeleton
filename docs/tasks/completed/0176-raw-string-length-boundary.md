## 目标

避免使用大量首尾空白包装合法内容绕过本地记录、报告快照和分享引用的字符串长度限制，降低异常同源数据进入页面状态和 URL 解析的风险。

## 范围

### 包含

- 本地会议主题同时校验原始值和去除首尾空白后的值。
- 报告快照参与者名称和分享引用主题拒绝超出原始长度边界的值。
- 增加首尾空白填充的回归测试，并更新边界文档。

### 不包含

- 不改变合法主题、参与者名称或报告快照的展示内容。
- 不引入服务端校验、账号系统或浏览器自动化测试。
