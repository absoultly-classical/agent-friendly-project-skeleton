## 目标

让本地 WebRTC 信令处理不依赖编译期类型，在收到畸形频道消息时安全忽略，保持当前会话状态稳定。

## 范围

### 包含

- 校验信令来源、类型、目标、会话描述和 ICE 候选的运行时结构。
- 忽略不符合结构的 `BroadcastChannel` 消息。
- 使用 fake WebRTC 增加畸形信令回归测试。

### 不包含

- 不增加鉴权或改变本地频道的访问边界。
- 不改变合法 offer/answer/ICE 协商流程。
