# 0096：新预约的独立本地房间号

- 状态：已完成
- 负责人：Codex
- 创建日期：2026-08-30
- 关联需求：REQ-009、REQ-012、REQ-014、REQ-019
- 关联决策：ADR-0001

## 目标

修正新建预约复用静态日程房间号的问题，让每次本机预约在本地 WebRTC 实验中使用独立且可恢复的房间号。

## 范围

### 包含

- 创建预约时生成不与静态日程冲突的数字房间号。
- 将生成的房间号随预约记录保存，刷新后继续使用。
- 补充预约房间隔离和持久化回归测试。

### 不包含

- 不把本地房间号升级为服务端会议凭据或访问控制。
- 不改变旧预约缺少房间号时的兼容回退行为。
