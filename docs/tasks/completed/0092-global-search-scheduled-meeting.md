- 状态：已完成

- 关联需求：REQ-009、REQ-012、REQ-019
- 关联决策：无

## 目标

让全局搜索能够找到当前用户刚创建并保存在本机的预约会议，避免搜索索引与“我的会议”实际内容不一致。

## 范围

### 包含

- 将当前 `scheduledMeeting` 转换为全局搜索结果。
- 与静态会议目录按会议 ID 去重，避免默认预约重复出现。
- 补充预约后全局搜索和定位回归测试。

### 不包含

- 不把当前页面上传资料或其他临时组件状态写入全局索引。
- 不实现服务端搜索、全文索引或跨设备同步。

## 约束与假设

- 约束：全局搜索只能展示当前前端已知的本地和演示数据。
- 约束：当前预约的会议 ID 由本机预约记录提供，和“我的会议”保持同源。
- 假设：将预约结果放在静态会议结果之前并按 ID 去重即可满足搜索定位；已通过页面回归验证。
