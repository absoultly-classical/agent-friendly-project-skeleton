# 0215：本地会议回放入口

- 状态：已完成
- 负责人：Codex
- 创建日期：2026-08-30
- 关联需求：REQ-003、REQ-006

## 目标

让已结束且生成本地录制的会议出现在“课堂回放”，并能从回放页继续预览、下载和复制本地引用。

## 实现记录

- 将带本地报告快照且 `recordingAvailable` 为真的历史会议映射为回放条目。
- 回放详情优先使用当前内存 Blob；刷新或切换后按会议号从 IndexedDB 恢复，并用序号防止异步恢复串档。
- 本地回放支持下载 WebM 和复制带会议号的本地回放引用；全局搜索可直接定位本地回放。
- 找不到媒体时只保留会议元数据并明确提示，不显示虚假的播放状态；静态演示回放继续保留原有发布语义。

## 验收标准

- [x] 已结束且有录制的本地会议会出现在回放列表。
- [x] 本地回放可使用真实 Blob 播放并下载。
- [x] 本地回放引用包含会议号，可按会议号恢复对应媒体。
- [x] 媒体缺失时不会伪造可播放内容。
- [x] 静态回放和历史未知引用保持兼容。
