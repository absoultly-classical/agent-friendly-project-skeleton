- 状态：已完成

- 关联需求：REQ-003、REQ-006

## 目标

让 `MediaRecorder` 异步异常与会后报告保持一致，避免录制失败后仍展示可用回放入口。

## 实现记录

- 将录制 hook 的错误状态纳入报告可用性派生值；当前会话没有有效 Blob 时不会保留页面级录制可用标记。
- 录制按钮启动失败时同步清除可用标记，避免失败重试前残留旧状态。
- 增加页面级异常回归测试，确认结束会议后不会生成虚假的回放入口。

## 验收标准

- [x] `MediaRecorder` 异步异常不会被报告快照标记为可用录制。
- [x] 录制启动失败不会保留上一轮页面级录制标记。
- [x] 相关自动化验证通过。
