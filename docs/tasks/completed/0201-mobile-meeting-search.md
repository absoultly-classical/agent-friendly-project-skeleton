## 目标

保证手机端会议中心仍能查找会议，不因响应式布局隐藏搜索框而丢失核心操作。

## 范围

### 包含

- 移动端会议中心搜索框保留显示。
- 允许工具栏换行，并让搜索框按剩余空间收缩。
- 增加 CSS 规则回归测试。

### 不包含

- 不改变会议搜索匹配逻辑或数据源。
- 不使用浏览器自动化测试。
