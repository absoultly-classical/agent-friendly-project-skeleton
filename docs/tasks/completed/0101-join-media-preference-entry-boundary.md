- 关联需求：REQ-008、REQ-019

## 目标

避免用户在主动加入会议时关闭的摄像头/麦克风偏好，跨页面入口泄漏到下一场首页日程或创建会议。

## 范围

### 包含

- 主动加入会议保留加入弹窗中的音视频选择。
- 首页课堂、首页日程、本机预约和创建会议进入时恢复音视频默认开启。
- 补充跨入口状态隔离回归测试。

### 不包含

- 不改变主动加入会议自身的媒体采集约束。
- 不引入跨会话或服务端保存的设备偏好。

- [x] 明确区分主动加入与直接进入的媒体偏好语义。
