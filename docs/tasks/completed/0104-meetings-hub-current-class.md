## 目标

让“我的会议”默认展示首页正在进行的课堂日程，保证会议发现入口与会议中心内容一致。

## 范围

### 包含

- 将首页当前课堂加入会议中心的即将开始列表。
- 让“今天的会议”摘要只统计今天日期的条目，不把未来日程计入今天。
- 与全局搜索补入逻辑按房间号去重。
- 补充会议中心默认可见性回归测试。

### 不包含

- 不扩展服务端会议索引或真实会议状态同步。
- 不改变课堂、日程和主动加入会议的房间号。
