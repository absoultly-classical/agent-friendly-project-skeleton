# 0004：WebRTC 自动化回归测试

- 状态：已完成
- 负责人：Codex

- 关联决策：ADR-0001

## 目标

为本地会议内核建立不依赖真实浏览器、摄像头或麦克风的自动化回归测试，使后续 Agent
能够仅依据项目文档和统一脚本验证核心会议能力。

## 完成内容

- 增加 Vitest、jsdom 与 Testing Library 测试环境。
- 在进程内模拟 MediaStream、媒体轨道、媒体设备、BroadcastChannel、
  RTCPeerConnection 和发送轨道替换。
- 覆盖房间号校验、权限失败、媒体采集、同房间协商、房间隔离、静音、关视频、
  屏幕共享、设备切换和离会清理。
- 增加 `test`、`test:watch`、`typecheck` 和 `check` 统一脚本。

## 约束与假设

- 约束：测试不得访问真实媒体硬件，也不得要求人工操作浏览器。
- 约束：模拟测试只验证应用控制逻辑，不能证明真实浏览器兼容性或跨网络媒体质量。
- 假设：后续会议内核仍通过标准 Web API 边界访问媒体与连接；如边界变化，应同步
  更新测试模拟实现。

## 验收结果

- [x] 自动化测试可在命令行一次性运行。
- [x] 测试执行时不请求真实摄像头、麦克风或屏幕权限。
- [x] 主要成功路径、失败路径和资源清理均有断言。
- [x] 类型检查和生产构建纳入统一检查入口。
- [x] 长期需求、架构和开发文档已更新。
