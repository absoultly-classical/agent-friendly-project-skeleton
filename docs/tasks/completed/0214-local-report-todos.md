# 0214：本地报告待办持久化

- 状态：已完成
- 负责人：Codex
- 创建日期：2026-08-30
- 关联需求：REQ-006

## 目标

让本机会议报告中的待办勾选和新增状态在关闭报告、返回首页、刷新后仍保持一致，同时不把静态演示报告写入本机状态。

## 实现记录

- 使用会议号作为本机报告待办的存储边界，保存任务 ID 与完成状态。
- 报告重新挂载时读取并合并已保存完成状态，保留报告默认任务和动态新增任务。
- 对待办 ID、载荷长度和布尔完成状态做基本校验，写入后回读确认。
- 只有带本地会话快照的报告持久化待办，静态历史演示报告继续保持演示状态。

## 验收标准

- [x] 本地报告勾选待办后重新打开仍显示已完成。
- [x] 本地报告新增任务时仍保留现有任务，并可继续勾选。
- [x] 静态演示报告不会产生本机待办存储。
- [x] 本机存储失败时报告仍可操作，不覆盖其他会话的提示。
