# 0070：明确当前会话报告的身份和分析边界

## 目标

修正当前本地会话报告仍固定显示“林老师”和课程活跃度演示分数的问题，让报告反映实际入会身份，并明确课程分析尚未接入。

## 范围

- 当前会话报告元信息使用本次入会名称。
- 当前本地会话不显示无法由本地快照推导的课程活跃度分数。
- 历史会议报告继续显示课程演示身份和活跃度数据。
- 增加 jsdom 回归测试，覆盖当前会话和历史会议的边界。

## 验收标准

- [x] 使用自定义名称加入并结束后，报告显示该名称。
- [x] 当前会话显示未接入课程活跃度分析，而不是固定 92 分。
- [x] 历史会议仍显示演示活跃度 92 和“较上次 +6”。
- [x] test、typecheck、lint、build 通过。

## 验证记录

2026-08-29：当前会话报告使用本次入会名称；本地快照无法计算课程活跃度时显示“— / 未接入课程分析”，历史报告继续显示演示分数。新增 3 条 jsdom 回归断言。`npm run check` 通过（2 个测试文件、95 项测试，typecheck 和 build 通过），`npm run lint` 通过，`git diff --check` 通过（仅有换行符提示）。

## 风险与边界

本地报告只能展示当前页面生命周期内的会话快照；课程活跃度、历史对比和远端教学分析仍需真实服务端数据。
