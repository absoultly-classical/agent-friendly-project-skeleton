## 目标

让会中控制按钮的开关和面板状态不只依赖文字、颜色或图标表达，使键盘用户和辅助技术能直接获知当前状态。

## 范围

### 包含

- 为音视频、屏幕共享和录制按钮补充按下状态语义。
- 为宫格/主讲布局和成员、聊天、课堂互动面板补充选择或展开状态语义。
- 使用 jsdom 回归测试覆盖状态变化。

### 不包含

- 不改变已有媒体轨道、录制演示和面板切换逻辑。
- 不使用浏览器自动化或真实设备测试。
