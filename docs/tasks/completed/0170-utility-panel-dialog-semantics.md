## 目标

让顶部搜索和通知按钮声明的弹出类型与实际工具面板角色一致，改善键盘和辅助技术导航。

## 范围

### 包含

- 搜索、通知临时面板使用非模态 `dialog` 角色。
- 保留面板的可读名称，并将可视标题作为描述关联到面板。
- 更新搜索、通知和互斥行为的语义回归测试。

### 不包含

- 不改变面板的打开、关闭、互斥和 Escape 行为。
- 不使用浏览器自动化测试。

## 实现记录

- 2026-08-30：发现按钮的 `aria-haspopup="dialog"` 与面板隐式 `complementary` 角色不一致。
- 2026-08-30：将工具面板改为非模态 `dialog`，并通过 `aria-describedby` 关联面板标题。
- 2026-08-30：同步更新测试查询角色，保留用户可见文案不变。
