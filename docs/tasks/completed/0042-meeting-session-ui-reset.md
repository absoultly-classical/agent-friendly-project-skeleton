## 目标

确保每次进入会议都会获得独立的临时 UI 状态，避免上一场会议的录制、布局、聊天和计时状态带入下一场会议。

## 范围

### 包含

- 进入新会议时重置录制状态、视频布局、互动选项、聊天内容和计时器。
- 保留既有活动发布状态清理和会议媒体清理逻辑。
- 使用 jsdom 验证结束一场会议后再次进入的状态边界。

### 不包含

- 不持久化聊天、录制或计时历史。
- 不实现真实录制服务或报告数据模型。

## 约束与假设

- 约束：会话重置不能清除用户尚未进入会议时的预约记录。
- 约束：新会议仍保留用户选择的入会媒体偏好和已有业务选项语义。
- 假设：录制、布局、聊天和计时均为当前 Home 生命周期内的临时状态。
