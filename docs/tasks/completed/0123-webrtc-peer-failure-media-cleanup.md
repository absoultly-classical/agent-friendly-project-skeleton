# 0123：WebRTC 对等连接失败释放媒体

- 状态：已完成
- 负责人：Codex
- 创建日期：2026-08-30
- 关联需求：REQ-014、REQ-018
- 关联决策：无

## 目标

连接进入 `disconnected` 或 `failed` 后，释放失败会话占用的本地媒体资源，避免错误状态下摄像头和麦克风仍被占用。

## 范围

### 包含

- 对等连接失败路径复用统一清理逻辑。
- 释放本地媒体、屏幕共享、peer、信令频道和待处理 ICE。
- 补充失败后媒体轨道停止及重新加入回归测试。

### 不包含

- 不实现跨网络自动重连。
- 不改变连接失败的用户提示和服务端边界。

## 计划

- [x] 定位 peer 失败路径与统一清理逻辑的差异。
- [x] 修正失败清理并补充回归测试。
- [x] 运行门禁、更新架构记录并归档。

## 验收标准

- [x] peer 失败后本地媒体和共享轨道均已停止。
- [x] peer 失败后可重新加入，且不复用旧资源。
- [x] 页面测试、类型检查、构建、Lint 和 HTTP 检查通过。
