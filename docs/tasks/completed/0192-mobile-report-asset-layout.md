## 目标

让手机宽度下的报告页、回放页、会议资料页保持内容层级清晰，标题、摘要、搜索、上传和报告操作不因横向排列而挤压或溢出。

## 范围

### 包含

- 产品页顶部工具区在手机宽度下换行，搜索框可收缩，上传按钮保持可达。
- 报告头部操作独占一行，报告摘要改为纵向布局，长标题允许换行。
- 报告卡片和出勤图表缩小间距，继续保留核心统计和操作。
- 增加响应式 CSS 源码回归测试，并同步需求与架构说明。

### 不包含

- 不改变报告统计、资料元数据、回放状态或业务数据。
- 不使用浏览器自动化或视觉截图作为测试依据。

## 实现记录

- 2026-08-30：手机端产品顶部工具区增加换行与弹性收缩规则，避免搜索/上传/通知操作互相挤压。
- 2026-08-30：报告页增加头部换行、摘要纵向排列和长标题换行规则，并压缩移动端卡片内边距。
- 2026-08-30：增加 2 项响应式 CSS 结构回归测试。
