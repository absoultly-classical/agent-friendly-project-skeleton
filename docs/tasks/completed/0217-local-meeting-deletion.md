# 0217：本机会议历史删除闭环

- 状态：已完成
- 负责人：Codex
- 创建日期：2026-08-30
- 关联需求：REQ-009、REQ-010

## 目标

让用户可以安全移除本机创建或已结束本机预约的会议历史，并同步清理会议号关联的录制和报告待办。

## 实现记录

- 在本机会议行菜单中增加“删除本机记录”，静态演示会议保持只读。
- 使用页面内确认对话框替代不可测试的原生确认 API；支持 Escape、Tab 焦点循环、进行中禁用操作和关闭后的焦点恢复。
- 删除前对本机会议元数据执行精确写回并回读校验，写入失败时保留列表记录并提示。
- 确认删除后移除对应会议历史、IndexedDB 录制 Blob 和 `learning-meeting-report-todos:{roomId}` 待办状态；附属清理失败会明确提示部分完成。

## 验收标准

- [x] 本机创建和本机预约历史可从会议行菜单发起删除。
- [x] 静态演示会议不出现删除操作。
- [x] 删除前可取消或使用 Escape 返回原会议行操作按钮。
- [x] 删除成功后会议历史、录制引用和报告待办均不再保留。
- [x] 本机存储写入失败时不误报删除成功，并保留会议记录。
