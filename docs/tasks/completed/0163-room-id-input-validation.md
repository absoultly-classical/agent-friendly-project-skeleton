## 目标

防止加入会议时静默删除任意非法字符，确保页面入口和 WebRTC 内核对会议号使用相同的格式化与校验规则。

## 范围

### 包含

- 允许空格和短横线作为输入分隔符并归一化为纯数字。
- 在页面加入入口和 WebRTC hook 入口拒绝其他字符。
- 增加归一化函数、页面和 hook 回归测试。
- 更新需求与架构文档。

### 不包含

- 不改变会议号 6–18 位长度边界。
- 不引入浏览器自动化测试或服务端房间校验。

- 约束：项目核心流程使用 Vitest/jsdom 验证，不使用浏览器测试。
