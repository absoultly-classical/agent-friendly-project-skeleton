# 0067：让报告互动明细与实际发布状态一致

## 目标

修正当前会话报告互动区域固定展示四项演示活动的问题，让明细与本次会话实际发布的课堂活动一致。

## 范围

- 当前会话报告只展示实际发布的活动。
- 当前会话没有发布活动时显示明确空状态。
- 当前会话已发布活动显示活动名称和“已发布”状态。
- 历史会议报告继续保留四项演示互动明细。
- 不改变活动发布逻辑和历史报告数据。

## 验收标准

- [x] 当前会话未发布活动时，互动明细显示未发布空状态，不渲染固定四项活动。
- [x] 当前会话发布活动后，互动明细只显示已发布活动及状态。
- [x] 历史会议报告仍显示四项演示活动。
- [x] 补充 jsdom 自动化测试，并通过 test、typecheck、lint、build。
