# 0119：累计时长统计一致性

- 状态：已完成

- 关联需求：REQ-009
- 关联决策：无

## 目标

让会议中心的累计会议时长反映本机已结束会议和预约报告快照，避免会议列表和摘要只更新数量、不更新时长。

## 范围

### 包含

- 在静态演示时长基数上累加已结束本机快照时长。
- 按房间号去重，避免本机历史与预约来源重复累加。
- 已知静态历史房间号被本机覆盖时不重复累加。
- 补充累计时长统计回归测试。

### 不包含

- 不推导缺少报告快照的旧记录时长。
- 不接入服务端统计或真实计费/计时系统。

## 计划

- [x] 审计会议中心数量和时长摘要的数据来源。
- [x] 纳入本机快照时长并补充测试。
- [x] 运行门禁、更新架构记录并归档。

## 验收标准

- [x] 唯一本机已结束快照会增加累计时长。
- [x] 同房间重复来源只增加一次。
- [x] 缺少快照的旧记录不产生伪造时长。
- [x] 页面测试、类型检查、构建、Lint 和 HTTP 检查通过。

## 风险与边界

12.6 小时仍是静态演示基数；本机新增时长仅代表当前设备保存的本地报告快照。

## 工作记录

- 2026-08-30：发现累计会议时长固定为静态值，与本机已结束报告快照不一致。
- 2026-08-30：按唯一房间号累加有效本机快照时长，并排除已知静态历史房间号和无快照旧记录。
