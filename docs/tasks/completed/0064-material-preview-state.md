# 0064：完善资料详情查看状态

## 目标

让会议资料详情中的“打开资料”产生可持续的本地查看状态，与回放和报告查看区域保持一致，降低操作完成后只有 Toast 的断层。

## 范围

- 点击“打开资料”后显示资料查看区域，保留文件名、来源、大小和类型。
- 根据文件类型显示视频、文档、表格或白板的本地预览说明。
- 查看区域可关闭；关闭后仍保留资料详情和搜索/文件夹筛选状态。
- 不读取或伪造本地文件内容，不接入云盘、预览服务或真实媒体播放。

## 验收标准

- [x] 资料详情点击“打开资料”后出现可关闭的资料查看区域。
- [x] 查看区域显示当前文件名，且不同类型有对应预览说明。
- [x] 关闭查看区域后资料详情仍然存在。
- [x] 补充 jsdom 自动化测试，并通过 test、typecheck、lint、build。

## 验证记录

2026-08-29：完成资料预览区域和按文件类型的本地预览说明，补充关闭后详情保持的回归；`npm run check` 通过（2 个测试文件、88 项测试，typecheck 和 build 通过），`npm run lint` 通过，`git diff --check` 通过（仅有换行符提示）。

## 风险与边界

预览区域是本地原型中的查看状态，不代表文件内容已经上传、同步或可被真实打开。
