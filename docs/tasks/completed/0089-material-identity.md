## 目标

为会议资料元数据增加稳定的本地唯一身份，避免重复上传同名文件时发生列表 key 冲突或记录互相覆盖。

## 范围

### 包含

- 为演示目录和本地上传资料建立唯一 ID。
- 列表使用 ID 渲染，保留同名资料的独立记录和预览入口。
- 补充重复文件名上传回归测试。

### 不包含

- 不读取文件内容、不做真实文件存储或云端同步。
- 不实现跨刷新恢复本地上传资料。

## 约束与假设

- 约束：资料只保存在当前页面内，文件名不是可靠的唯一身份。
- 约束：上传同名文件不应触发 React key 冲突，也不应丢失已有记录。
- 假设：使用 `crypto.randomUUID()` 生成当前页面内 ID；已通过重复上传测试验证。
