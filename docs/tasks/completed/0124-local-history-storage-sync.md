# 0124：本机历史跨窗口同步

- 状态：已完成

- 关联需求：REQ-006、REQ-018
- 关联决策：无

## 目标

让同源另一个窗口对本机预约或会议历史的新增、更新、删除能及时反映到当前页面，减少必须刷新才能看到的状态分叉。

## 范围

### 包含

- 监听本机预约和本机创建会议对应的 `storage` 事件。
- 按变更键重新读取并校验本机数据，支持删除和清空事件。
- 补充页面回归测试。

### 不包含

- 不引入服务端同步、账号同步或跨设备数据。
- 不把当前窗口自身的 React 状态更新改成依赖 `storage` 事件。
