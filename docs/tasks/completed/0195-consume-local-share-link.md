# 0195：消费本地分享引用参数

- 状态：已完成

- 更新日期：2026-08-30

## 目标

避免本地报告、回放或会议邀请引用在首次打开后继续留在 URL 中，导致返回首页或刷新页面时旧目标重复触发。

## 范围

### 包含

- 首次读取分享引用后移除 `share`、`title`、`mode`、`snapshot` 和 `room` 参数。
- 保留 URL 中其他非分享查询参数与 hash。
- 补充报告分享引用被消费的回归断言，并同步需求与架构说明。

### 不包含

- 不改变分享引用的校验规则、报告/回放内容或会议邀请预填行为。
- 不引入路由服务或服务端分享资源。
- 不使用浏览器自动化测试。

## 实现记录

- 2026-08-30：增加本地分享参数消费函数，在初始化分享解析后清理相关查询参数。
- 2026-08-30：补充报告分享引用打开后 URL 被清理的回归断言。
