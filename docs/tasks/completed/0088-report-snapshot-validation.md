## 目标

收紧本地报告分享快照的输入校验，确保 URL 中恢复的统计不会超出本地模型或产生重复活动明细。

## 范围

### 包含

- 校验时长、聊天数量和窗口数量为整数。
- 将本地窗口数量限制在 0–2，并拒绝重复的活动 ID。
- 为非法快照补充报告回退测试和文档说明。

### 不包含

- 不引入服务端签名、鉴权或持久化报告。
- 不改变历史演示报告的数据。

## 约束与假设

- 约束：本地实验最多展示当前窗口和同源远端窗口两个参与窗口。
- 约束：一个活动在会话快照中只能出现一次。
- 假设：非法深链接应回退到对应模式的演示报告；已通过 jsdom 深链接测试验证。
