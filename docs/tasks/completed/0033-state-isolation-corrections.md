## 目标

修正上一轮实现中发现的两个状态边界问题：资料清除筛选必须恢复完整列表，课堂活动发布记录必须只属于当前会议。

## 范围

### 包含

- “查看全部”同时清除资料搜索词和文件夹筛选。
- 进入新会议时清空上一场会议的活动发布记录。
- 从历史会议直接打开报告时不带入当前会话活动记录。
- 补充对应 jsdom 回归测试并更正相关任务记录。

### 不包含

- 不引入跨会议的服务端活动历史模型。
- 不改变资料和报告的演示数据内容。

## 约束与假设

- 约束：进入新会议必须创建新的前端会话边界，不能复用上一会议的活动发布状态。
- 约束：历史报告只显示该报告自身已有内容，不读取当前未结束会议的临时状态。
- 假设：资料筛选和会议切换均可通过 jsdom 的页面操作复现并验证。
