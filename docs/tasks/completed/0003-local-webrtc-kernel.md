## 目标

让原型具备可在本机验证的真实音视频能力：两个同源浏览器窗口通过相同房间号建立
点对点连接，并能操作真实媒体轨道。

## 完成内容

- 浏览器摄像头和麦克风权限、采集与本地预览。
- 基于房间号和 BroadcastChannel 的本地双窗口信令。
- RTCPeerConnection offer、answer、ICE 与连接状态处理。
- 真实静音、摄像头开关、摄像头和麦克风切换。
- 真实屏幕共享、恢复摄像头、离会与远端离开处理。
- 权限失败、等待、连接中、已连接和连接异常反馈。

## 验收结果

- [x] 会议页提供真实设备加入入口。
- [x] 两个本地窗口可通过同一房间号进行连接协商。
- [x] 会中控制直接作用于浏览器媒体轨道。
- [x] 项目明确标注本机实验与跨网络生产会议的边界。
- [x] 本地生产构建通过，线上版本保持不变。
