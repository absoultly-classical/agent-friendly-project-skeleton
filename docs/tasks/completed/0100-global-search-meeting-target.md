# 0100：全局搜索会议目标可见性

- 状态：已完成
- 负责人：Codex
- 创建日期：2026-08-30
- 关联需求：REQ-009、REQ-019
- 关联决策：无

## 目标

让全局搜索中的会议结果进入“我的会议”后仍能看到对应会议条目，避免结果只切换页面而目标在列表中消失。

## 范围

### 包含

- 将会议搜索结果标题传递到会议中心。
- 对当前索引中但会议中心原列表未展示的首页日程，补充可见的本地会议条目。
- 保持预约和静态会议按房间号去重。
- 补充会议搜索定位回归测试。

### 不包含

- 不扩展服务端会议搜索或历史会议索引。
- 不改变会议进入、报告和本地 WebRTC 行为。

## 计划

- [x] 传递会议搜索目标并让目标条目在会议中心可见。
- [x] 补测试、更新架构说明，运行完整门禁并归档。

## 验收标准

- [x] 搜索首页当前会议结果后，会议中心出现对应会议条目。
- [x] 已存在于会议中心的会议结果不会重复显示。
- [x] 本机预约和既有搜索导航行为不受影响。
- [x] 相关测试、类型检查、Lint、构建和 diff 检查通过。
