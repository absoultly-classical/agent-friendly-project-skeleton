## 目标

让当前本地会话报告中的聊天消息数量只反映用户进入会议后产生的消息，避免把页面加载时的演示聊天误报为本次会话活动。

## 范围

### 包含

- 进入会议时将本次会话新增消息计数清零。
- 发送本地消息和收到同源远端消息时递增计数。
- 当前会话报告使用该计数；历史会议继续使用演示数据。
- 补充 jsdom 回归测试并更新本地报告边界说明。

### 不包含

- 不移除会中用于展示界面结构的演示消息。
- 不接入服务端消息持久化、跨设备消息同步或真实历史聊天记录。

## 约束与假设

- 约束：当前版本的聊天频道仅在同源本地窗口间传输，产品数据仍是演示数据。
- 约束：报告快照只存在于当前页面生命周期。
- 假设：将本地和同源远端窗口在入会后的新增消息合并计数，符合当前报告的“本次会话”语义；通过自动化测试验证。
