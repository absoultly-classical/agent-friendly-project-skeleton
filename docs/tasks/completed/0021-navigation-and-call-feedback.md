## 目标

让主导航的当前页面状态可被辅助技术准确识别，并让会中设备或连接异常在会议画布内持续可见，避免用户只看到颜色变化或在隐藏的入会面板里寻找错误。

## 范围

### 包含

- 为主导航按钮补充当前页面语义和键盘可感知状态。
- 为实时会议连接状态补充可访问的实时播报语义。
- 在已进入会议后展示设备、共享或连接错误，并补充可执行的离开恢复入口。
- 使用 jsdom 测试覆盖这些状态。

### 不包含

- 不引入新的服务端信令、权限模型或真实媒体基础设施。
- 不使用浏览器自动化作为本任务验证方式。

## 约束与假设

- 约束：本地 WebRTC 仍然只支持同源窗口实验，错误恢复必须保持在现有前端状态边界内。
- 约束：完整验证使用项目已有的 jsdom、lint、类型检查和生产构建脚本。
- 假设：将错误展示为会议画布中的可操作提示即可覆盖设备切换、屏幕共享和连接协商失败；通过测试验证。
