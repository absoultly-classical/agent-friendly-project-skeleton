## 目标

当本机存储不可写时，明确告知用户会议历史或报告状态无法持久化，避免把仅存在于当前页面的状态误认为已保存。

## 范围

### 包含

- 快速会议创建时反馈历史未保存，但继续允许用户进入会议。
- 结束本机会议时反馈历史状态保存失败。
- 手动生成历史报告时反馈报告状态保存失败。
- 为上述路径补充本地页面回归测试。

### 不包含

- 不接入云端同步、数据库或服务端存储。
- 不因本机存储不可用而阻止真实本地 WebRTC 入会。

## 计划

- [x] 定位本机会议和报告状态的写入路径。
- [x] 实现失败反馈并补充测试。
- [x] 运行门禁、更新架构记录并归档。

## 验收标准

- [x] 三条本机写入失败路径都有明确反馈。
- [x] 存储正常时既有会议、报告和测试行为不变。
- [x] 页面测试、类型检查、构建和 Lint 通过。

## 风险与边界

提示只说明当前设备无法持久化；页面内状态仍可继续使用，刷新后的恢复能力取决于本机存储是否可用。
