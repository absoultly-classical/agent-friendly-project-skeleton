## 目标

让会中会议号的复制按钮真正写入系统剪贴板，并在剪贴板能力不可用时给出明确的手动复制反馈。

## 范围

### 包含

- 接入 `navigator.clipboard.writeText` 复制纯数字会议号。
- 处理 API 不存在、权限失败和写入异常。
- 用 jsdom 覆盖成功与失败提示。

### 不包含

- 不实现跨设备邀请、短信或第三方分享。
- 不使用浏览器自动化测试。

- `docs/product/overview.md`

## 约束与假设

- 约束：剪贴板写入只发生在用户点击会议号复制按钮后。
- 约束：本地实验仍不提供服务端会议号或访问控制。
- 假设：不支持剪贴板时保留会议号在界面中的可见性即可让用户手动复制。
