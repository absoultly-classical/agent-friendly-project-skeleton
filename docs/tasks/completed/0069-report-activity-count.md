# 0069：让会后报告互动数量与本次会话一致

## 目标

修正当前本地会话报告的“课堂互动”标题仍固定显示 4 项活动的问题，让数量与本次会中实际发布的活动保持一致。

## 范围

- 当前会话报告显示实际发布的活动数量。
- 当前会话没有发布活动时明确显示 0 项已发布。
- 历史会议报告继续显示演示数据的 4 项活动。
- 增加 jsdom 回归测试，覆盖有活动和无活动两种状态。

## 验收标准

- [x] 当前会话发布 1 项活动后，互动标题显示 1 项已发布。
- [x] 当前会话未发布活动时，互动标题显示 0 项已发布。
- [x] 历史会议报告仍显示 4 项活动。
- [x] test、typecheck、lint、build 通过。

## 验证记录

2026-08-29：当前会话报告互动标题改为读取本次实际发布数量，未发布时显示 0 项已发布；历史会议继续显示 4 项活动。新增 3 条 jsdom 回归断言。`npm run check` 通过（2 个测试文件、94 项测试，typecheck 和 build 通过），`npm run lint` 通过，`git diff --check` 通过（仅有换行符提示）。

## 风险与边界

当前报告只能确认活动是否在本地页面发布，不能推断远端学生是否完成活动；活动完成率仍需后续接入真实课堂服务。
