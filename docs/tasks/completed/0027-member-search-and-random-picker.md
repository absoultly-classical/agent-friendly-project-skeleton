## 目标

让会中成员管理和课堂互动入口具备真实的操作结果：成员搜索能缩小名单，随机选人能从在线学生中选出具体成员。

## 范围

### 包含

- 将成员搜索框改为受控输入并按姓名、身份和出勤状态过滤。
- 无匹配成员时显示明确状态。
- 在随机选人活动中增加随机抽取按钮、结果展示和反馈。
- 使用 jsdom 覆盖筛选和随机选择。

### 不包含

- 不同步远端成员权限、成绩或真实课堂活动服务。
- 不改变签到、投票和测验的演示统计。

## 约束与假设

- 约束：随机候选只包含当前在线学生，不包含主持人和未到成员。
- 约束：结果只保留在当前会中前端状态，不写入服务端或报告。
- 假设：当前成员名单足以支撑本地原型中的随机选人演示；通过测试验证。
