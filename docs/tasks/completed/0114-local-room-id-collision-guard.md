## 目标

确保新建预约和快速会议不会复用已保存的本机历史会议号，避免历史搜索和本地房间状态误合并。

## 范围

### 包含

- 将本机历史会议号加入新会议号的保留集合。
- 在随机候选和固定回退候选两条路径上避免碰撞。
- 修正多窗口测试为显式共享房间号，而不是依赖随机号副作用。
- 补充本机历史房间号碰撞回归测试。

### 不包含

- 不实现服务端会议号分配或全局唯一性保证。
- 不改变主动加入流程输入的房间号语义。
