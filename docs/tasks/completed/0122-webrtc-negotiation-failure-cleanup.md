# 0122：WebRTC 协商失败清理

- 状态：已完成

## 目标

当本地 WebRTC 信令协商失败时，立即释放失败会话的 peer、信令频道和媒体轨道，避免旧异步信令继续改写错误状态，并让用户可以干净地重新加入。

## 范围

### 包含

- 协商消息处理失败时进入错误状态前清理当前连接资源。
- 忽略清理后返回的旧协商异常，避免覆盖新一轮入会状态。
- 补充失败清理和重新加入回归测试。

### 不包含

- 不实现跨网络自动重连或服务端信令。
- 不改变媒体权限错误和设备切换错误的处理语义。
