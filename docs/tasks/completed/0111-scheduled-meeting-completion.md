## 目标

让预约会议结束后转入已结束列表，并在刷新后保留结束状态和报告快照。

## 范围

### 包含

- 为本机预约记录保存 upcoming/past 状态。
- 结束预约会议时保存会话报告快照和生成状态。
- 会议中心按状态展示预约记录，搜索定位已结束预约时进入正确标签。
- 补充预约生命周期回归测试并更新架构说明。

### 不包含

- 不实现服务端日历、服务端会议状态或跨设备同步。
- 不改变静态演示日程和主动输入会议号的生命周期。

## 验收标准

- [x] 预约会议结束后不再出现在“即将开始”，而出现在“已结束”。
- [x] 预约记录的结束状态和报告快照刷新后仍可恢复。
- [x] 本机预约的报告生成选项继续影响结束后的报告状态。
- [x] 全量测试、类型检查、构建、Lint、diff 和 HTTP 检查通过。
