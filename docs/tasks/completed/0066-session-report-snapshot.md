# 0066：让当前会话报告使用真实本地快照

## 目标

修正当前会话结束后报告仍显示固定时长、互动数量和聊天数量的问题，让报告表达当前页面实际产生的本地会话数据。

## 范围

- 结束当前会话时保存会话时长、聊天消息数和已发布活动数。
- 当前会话报告使用快照显示会议时长、互动数量和聊天数量。
- 历史会议报告继续使用演示摘要数据。
- 进入新会议时清除上一场会话快照。
- 保留既有录制、报告生成和回放状态语义。

## 验收标准

- [x] 当前会话报告显示结束时的本地会话时长，而不是固定平均在线时长。
- [x] 当前会话报告显示当前会话的已发布活动数和聊天消息数。
- [x] 历史会议报告仍显示其演示统计，不被当前会话数据覆盖。
- [x] 新会议不会继承上一场报告快照。
- [x] 补充 jsdom 自动化测试，并通过 test、typecheck、lint、build。

## 验证记录

2026-08-29：完成当前会话报告快照，动态展示会话时长、已发布活动数和聊天消息数；历史报告保留演示数据，新会议清除快照。`npm run check` 通过（2 个测试文件、92 项测试，typecheck 和 build 通过），`npm run lint` 通过，`git diff --check` 通过（仅有换行符提示）。

## 风险与边界

快照只存在于当前页面生命周期，不是服务端持久化报告；出勤名单和活动完成比例仍是演示数据，后续接入课程服务时需要替换为真实数据源。
