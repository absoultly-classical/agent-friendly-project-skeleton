# 0063：完善会议列表更多操作菜单

## 目标

让“我的会议”列表中每行的更多操作提供真实的本地页面动作，不再点击后只显示“暂无可用操作”。

## 范围

- 打开和关闭当前会议行的操作菜单。
- 提供复制会议号动作，并反馈成功或失败。
- 即将开始的会议提供进入会议；已结束的会议提供查看报告。
- 支持 Escape 关闭菜单，切换页面或打开另一行菜单时清理旧菜单。
- 不接入服务端会议管理、真实权限或远端数据修改。

## 验收标准

- [x] 即将开始的会议更多操作可打开菜单，菜单显示复制会议号和进入会议。
- [x] 已结束的会议更多操作可打开菜单，菜单显示复制会议号和查看报告。
- [x] 复制会议号使用当前行会议号并显示结果反馈。
- [x] 操作菜单支持 Escape 关闭，且同一时间只有一个菜单。
- [x] 补充 jsdom 自动化测试，并通过 test、typecheck、lint、build。

## 验证记录

2026-08-29：完成会议行操作菜单、当前会议号复制、按会议状态提供进入会议/查看报告，并补充 Escape 和单菜单回归；`npm run check` 通过（2 个测试文件、87 项测试，typecheck 和 build 通过），`npm run lint` 通过，`git diff --check` 通过（仅有换行符提示）。

## 风险与边界

动作只改变当前本地原型的视图、剪贴板或报告页面；取消预约仍沿用既有的独立操作，不在本任务中改变。
