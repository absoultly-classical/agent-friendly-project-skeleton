# 任务记录

任务文档是可恢复的执行记录，不是缩小版的产品或架构文档。它只保存当前目标、范围、
上下文链接、进展、证据和交接信息。长期有效的结论要提升到相应权威文档。

## 新任务

用户可以直接对 Agent 说：

> 请根据任务模板为这项工作建立任务记录，分配一个未使用的编号，保存到 active
> 目录，并登记到 ACTIVE.md。先让我确认目标、范围和验收标准，再开始实现。

Agent 应完成以下动作：

1. 复制 `TEMPLATE.md`，使用外部工单编号或下一个未使用的四位编号。
2. 文件名采用“编号-简短英文标识.md”，保存到 `active/`。
3. 在 `ACTIVE.md` 中增加一行，并写明一个可以立即执行的下一步。
4. 工作中在关键节点更新计划、工作记录和验证证据。

## 暂停与交接

用户可以说：

> 请暂停当前任务，把实际进度、改动文件、验证结果、风险和下一步写入任务文档，
> 确保下一位 Agent 不需要聊天记录就能继续。

## 完成任务

Agent 应将任务状态改为“已完成”，把文件从 `active/` 移到 `completed/`，从
`ACTIVE.md` 删除对应行，并确认所有长期结论已经写入权威文档。任务编号不得复用。
