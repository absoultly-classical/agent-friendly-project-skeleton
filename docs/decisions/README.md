# 决策记录

遇到影响长期、难以撤销或会约束后续工作的选择时，应建立决策记录。例如：技术选型、
数据归属、公共接口、安全策略、依赖方向和兼容性政策。

## 如何让 Agent 建立决策记录

直接告诉 Agent：

> 请根据决策模板记录这项选择。说明为什么现在必须决定、考虑过哪些方案、最终选择
> 及其影响，并把它加入决策索引。

Agent 应遵循以下规则：

1. 复制 `TEMPLATE.md`，使用下一个四位编号。
2. 在依赖该选择的实现之前或同一次改动中完成记录。
3. 状态使用：`提议中`、`已采纳`、`已拒绝`、`已废弃`、`已被替代`。
4. 不要改写历史来隐藏旧决定。新建一条记录，并把旧记录标为“已被替代”。
