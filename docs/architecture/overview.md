# 架构概览

## 当前形态

第一版是可部署的前端交互原型，用于验证信息架构、核心流程和产品体验。它不接入
真实用户、课程、音视频或录制服务，界面数据均为演示数据。

## 组件

| 组件 | 职责 | 拥有的数据或行为 | 允许依赖 |
| --- | --- | --- | --- |
| 首页与会议大厅 | 会议发现、快速创建、预约和加入 | 当前页面、会议入口状态 | 前端状态与演示数据 |
| 创建会议面板 | 选择会议/课堂模式和课程班级 | 创建表单与邀请范围 | 演示课程数据 |
| 会中控制台 | 视频宫格、主持控制和会议信息 | 音视频开关、布局、计时 | 前端状态 |
| 成员与聊天侧栏 | 成员状态、身份和即时讨论 | 面板选择、消息列表 | 演示成员数据 |
| 教学互动 | 签到、投票、测验和随机选人 | 活动选择与发布状态 | 演示活动数据 |
| 课后报告 | 汇总出勤、互动、录制和待办 | 报告维度切换 | 演示报告数据 |

## 关键流程

1. 用户从大厅选择快速会议、预约会议或加入会议。
2. 课堂模式关联课程和班级，形成默认参会名单。
3. 用户进入会中控制台，使用会议控制和教学互动。
4. 结束会议后进入课后报告，查看出勤与互动结果。

## 系统不变量

- 课程、班级和成员身份由学习通统一身份体系提供，不在会议系统重复维护。
- 教学互动产生的成绩必须保留活动来源和人工确认能力。
- 未经授权的参会者不能看到课程名单、成绩或受限资料。
- 原型数据与生产数据必须有清晰边界。

## 后续生产架构边界

真实版本需要独立的会议编排服务、实时信令、媒体转发服务、录制转码、消息服务、
课堂活动适配层和会后分析流水线；前端不能直接依赖媒体基础设施或持有长期凭据。
